Method. Many sources organised into a structured, rigorous understanding. It costs an order of magnitude more than any other style, so use it only when depth was asked for. Say at the start that this is the expensive one and how large you expect the run to be.
1. Decompose the ask into sub-questions. Check the tree for gaps (a part of the subject no sub-question covers) and overlaps (two that will fetch the same sources). Write the tree down.
2. State the rival positions, schools or readings of the central questions before gathering. The synthesis tests them against each other. It does not drift toward whichever you found first.
3. Go shallow first. Do a breadth pass over all sub-questions before depth on any. Then re-plan from what the sweep showed: merge sub-questions that turned out to be one, split any that hid two, add the branch nobody expected.
4. Depth per branch, picking sources that separate the rival positions. Stop each branch when new pages only repeat. Give the saved effort to branches that are still thin, not to the ones already well covered.
5. Triangulate hard. Collapse sources of one origin before counting agreement. Every major claim carries its independent-source count. A single-source claim stays flagged as single-source however central it is.
6. Argue against each major conclusion at full strength. Look for the strongest opposing evidence. Check the decomposition again: did a sub-question go unanswered and quietly drop out of the draft? Are disputes being averaged into a false consensus?

Delivery. In the summary (and in the file your order names, if long):
- a structured report that follows the re-planned tree;
- every finding tagged with its tier, provenance and independent-source count;
- disputes and opposing views shown as disputes, never merged into a middle;
- a coverage-gaps section: the sub-questions and sources still open;
- the delta: what a reader who knew the standard account learns here.

Avoid. A long list of sources with no claim tested against another. Length is not rigour.
