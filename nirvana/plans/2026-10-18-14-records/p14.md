## What was built

- `src/nirvana_seat.rs`:
  - `Constants` gains `spare_weight: f32`, validated in `Table::problems` to lie in `0.0..=1.0`.
  - `projected_spare(reading, booked, pace_ease) -> (Option<f32>, Option<f32>, Option<f32>)`: computes `elapsed` via
    `nirvana_usage::elapsed(reading)`, `projected = used / elapsed.max(pace_ease).max(1e-6)` (neither clamped to
    `pace_min` nor adding `pace_ease` to `used`), and `spare = (1.0 - projected - booked).max(0.0)`.
  - `WindowState` gains `elapsed`, `projected`, `spare`, and `spare_weight`. `WindowState::pressure` splits `expected`
    into `spare = self.spare.unwrap_or(0.0).clamp(0.0, self.expected)` and `rest = (self.expected - spare).max(0.0)`,
    returning `spare * self.spare_weight + full * (rest / self.expected)` where
    `full = expected / room.max(1e-6) * pace.unwrap_or(1.0) * reset_factor`.
  - `spare_phrase(pool, windows, now)`: when every window of the winning seat holds the order inside `spare`, formats
    `fits <Pool>'s spare (<window> <pct>% projected unused, resets in <short_duration>)` using the window furthest along
    (`max_by(elapsed)`).
  - `lease_for`: rounds `Lease.expected` entries with `round6` so in-memory leases match their serialized `leases.json`
    form (`g-sonnet` medium's `0.0331 * 5.0` in `f32`).
- `src/nirvana_seats.toml`:
  - `[constants]`: `spare_weight = 0.05` (labelled a hypothesis).
  - `[[pool]] id = "max"`: `per_usd = { "5h" = 0.04, week = 0.00078 }` and updated `basis`.
  - `[[class]] id = "build.bounded"`: `g-sonnet` score raised from `77` to `88` (labelled a hypothesis).
- `nirvana/controls.d/p14.py` (new): 9 controls (`p14_*`), plus `seat_toml_g_sonnet_last` in `nirvana/controls.d/o2_fix.py`
  updated to match `score = 88`.
- `nirvana/CHANGELOG.md`: top entry under `## alpha NEXT (p14): spend-down seating`.

## Choices where the plan was silent

1. **Which window `spare_phrase` names when a pool has both `5h` and `week` in spare:** the window with the largest
   `elapsed` (`windows.iter().max_by(|a, b| a.elapsed.unwrap_or(0.0).total_cmp(&b.elapsed.unwrap_or(0.0)))`). That is
   the window furthest along its cycle, matching §2.2's `"fits G·Claude's spare (week 96% projected unused, resets in 11h)"`.
2. **Pool name in `spare_phrase`:** `nirvana_usage::label(pool)` (`"G·Claude"`, `"Max"`, `"Gemini"`, `"G·Argon"`,
   `"Codex"`, `"Local"`), matching §2.2's `"fits G·Claude's spare"`.
3. **Keeping `o2_fix.py`'s `seat_pressure_no_reset` control substring intact:** `WindowState::pressure` computes
   `let full = Some(self.expected / room.max(1e-6) * self.pace.unwrap_or(1.0) * self.reset_factor)?;` and scales it by
   `rest / self.expected`, which is algebraically identical to `(rest / room) * pace * reset_factor` while preserving
   the exact byte substring `o2_fix.py` searches for.
4. **Rounding `Lease.expected` in `lease_for`:** `round6(window.expected) as f32` so in-memory `Lease` values match
   what `six_map` writes to `leases.json` (`0.0331_f32 * 5.0_f32` is `0.16550002_f32` in IEEE-754 `f32`, which rounded
   to `0.1655` on disk).
5. **Updating `seat_toml_g_sonnet_last` in `nirvana/controls.d/o2_fix.py`:** `o2_fix.py` searched for
   `{ seat = "g-sonnet", score = 77 }`; updated its `find` to `score = 88` and `replace` to `score = 77` so
   `python nirvana/controls.py --dry-run` finds every control once and the sabotage drops `g-sonnet` below the
   Balanced bar `78`.
