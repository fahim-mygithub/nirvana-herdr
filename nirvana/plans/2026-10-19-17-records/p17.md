## What was built

- `src/nirvana_subagents.rs`:
  - `Subagent`, `SubagentsView`, `SubagentProvider`, and `SubagentState` core domain types.
  - Project folder encoding (`encode_project_folder`) converting all non-alphanumeric characters to `-` for matching Claude Code's `~/.claude/projects/` directory naming.
  - Three-tier session resolution (`resolve_claude_session`): (1) herdr's `agent_session`, (2) Nirvana session record, (3) newest `.jsonl` written while the agent ran. Implemented strict shared-folder conflict refusal when two Claude panes share a project directory without distinguishing sessions.
  - Fast transcript tail parser (`read_file_tail`, `parse_transcript_tail`) reading at most 64KB from transcript files to extract latest assistant turn, model, tokens, and timestamp without reading entire multi-megabyte files.
  - Metadata parser (`parse_meta_json`) extracting `agentType`, `description`, `model`, `finished`, `parentAgentId`, and `name`.
  - Subagent state resolution (`determine_subagent_state`) handling `finished: true`, failed markers, and the 5-minute inactivity rule for legacy meta files without a finished flag.
  - 10-minute visibility filter for finished/failed subagents.
  - Hierarchical workflow nesting (`nest_subagents`) ordering depth-1 child subagents directly beneath their parent subagent.
  - Token and elapsed time formatters (`format_tokens`, `format_elapsed`) matching Claude Code's conventions.
  - Model name normalizer (`format_model`, `short_model`) aligning with strip doctrine (`Sonnet 5.5`, `Opus 5.5`, `Haiku 5.5`, `Gemini 3.8 Flash`, `Gemini 4 Argon`, `inherit`).
  - agy readers: seat orders (`read_seat_orders`) from run journal and stream JSONL; agy jobs (`read_agy_jobs`); process walk (`find_agy_processes_under`, `parse_cmdline_model`, `find_child_pids`) for Bash-spawned agy processes.
  - Seat worker pane tracking (`record_worker_pane`, `is_seat_worker_pane`) ensuring worker panes are not duplicated as top-level agent rows.
  - Off-draw-path caching engine (`ENTRIES`, `poll`, `take_changed`, `cached`, `update_pane_query`) running on background threads every 2s for active subagents and 10s when idle.
- `src/client/shell/agent_sidebar.rs`:
  - `AgentRow` extended with `subagents: Vec<Subagent>` and `subagents_overflow: usize`.
  - `is_narrow_agent_panel(width)` threshold (< 34) and adaptive `agent_row_lines` height accounting.
  - Top-level agent rows filtered against `is_seat_worker_pane`.
  - Subagent rendering in both flat and grouped views: provider marks (`✻` Claude, `◆` Gemini, `●` Local) with doctrine colors, model, elapsed/status/tokens, line 2 description (wide only), `+N more` overflow, dimming for completed subagents, and click targeting routing to `hits.agents`.
- `src/client/shell/endpoint_agents.rs`:
  - Updated expanded agent list rendering callback to query `agent_row_lines` for correct row height allocation.
- `nirvana/controls.d/p17.py`:
  - 17 sabotage controls verifying every assertion.

## Findings & Notes

1. **agy Database Probe (§4):**
   - Probed a copied agy conversation database `target/p17-probe/probe.db` (copied from `~/.gemini/antigravity-cli/conversations/<uuid>.db`).
   - SQLite tables discovered: `trajectory_meta`, `steps`, `gen_metadata`, `executor_metadata`, `trajectory_metadata_blob`, `parent_references`.
   - All token and step payloads are stored as serialized Protocol Buffer binary blobs (`gen_metadata.data`, `steps.step_payload`) without plaintext or SQL column token totals.
   - Per plan specification, Bash-started agy rows show `-` for tokens.
2. **Claude Code Live Activity Line (§3):**
   - Verified that live activity lines (e.g. "Fetching FEIYASHI variant prices") are held in Claude Code memory only and not written to disk. The subagent row displays the static description from metadata instead.
3. **Claude Driving agy vs Direct Execution (§1):**
   - Verified that direct invocation (`herdr seat run`, direct process spawn) remains optimal. Claude subagent first turns re-read 17k to 55k tokens of context per turn, making intermediary Claude wrapper drivers token-inefficient.
