## What was built

1. **§2: Orchestrator usage logging via hook**
   - Implemented `read_transcript_usage(path: &Path, offset: u64, prior_seen_ids: &[String]) -> std::io::Result<(Tokens, u64, Vec<String>)>` in `src/nirvana_claude.rs`. Reads assistant lines, extracts `message.usage`, advances offset only to last newline, deduplicates across identical `message.id`s taking the max per slot within a read, remembers the last 200 counted ids, and skips `"isSidechain": true`.
   - Keyed offsets by session ID in `<home>/nirvana/usage-offsets/<session_id>.json`.
   - On `SessionStart` with resume and no stored offset, initializes offset to transcript length and counts nothing.
   - Added subcommand `log-usage` registered in `nirvana/claude/hooks/hooks.json` under `SessionStart` (resume only) and `Stop`.
   - Appends `Kind::Usage` to the most recent open run of the project.

2. **§3: Nirvana Claude own-edit limit**
   - Defined pure function `edit_budget(baseline: &EditState, now: &EditState, limit: EditLimit) -> Option<String>` enforcing at most 1 file and 30 lines outside an order (added + deleted lines; content snapshot with multiset difference for files <= 256 KiB with 4 MiB total cap; hash fallback above cap; clean files count 0).
   - Untracked files cached by `(size, mtime)` to keep tool-call costs down. Fail-open if > 2,000 dirty or untracked paths. Binary files count as 1 file, 0 lines.
   - Session-keyed baselines under `<home>/nirvana/edit-baselines/<session_id>.json`. When `check_edit` finds no baseline for session, writes one from current state and returns `Ok(())` without blocking.
   - `is_out_of_scope` exempts `.nirvana/`, `.claude/`, memory paths under `~/.claude/projects/` (by absolute path only), and `.nirvana/worktrees`.
   - `prompt-baseline` subcommand registered on `UserPromptSubmit`.
   - `guard-edit` subcommand on `PreToolUse` for `Edit|Write|MultiEdit` blocking single calls > 30 lines (`guard_edit_decision`).
   - `check-edit` subcommand on `PostToolUse` outputting only `{"decision": "block", "reason": ...}` (`check_edit_decision`). Grammatical count ("1 file", not "1 files").
   - Updated `nirvana/claude/ROLE.md`.

3. **§4: Preserving model and effort override across retries**
   - In `nirvana_gate::send_back`, propagated `seated.override_reason` to child request as `override_seat = (<parent seat>:<parent effort>, <parent reason>)` and marked `inherited_override = true`. Set `child.override_reason = seated.override_reason.clone()`.
   - If `pick` fails with `request.inherited_override == true`, falls back to pick again without override and journals `inherited override <seat> refused: <why>; the rule picked` with `override_reason: None`.
   - In `nirvana_seat::book_pick`, avoided incrementing `leases.runs.entry(run).overrides` when `pick.inherited_override` is true.
   - In `nirvana_seat::evaluate`, exempted `request.inherited_override` from the `world.overrides_used >= constants.overrides_per_run` check.
   - In `nirvana_worker::rate_limited`, checked if rate limit occurred on `seated.pool`. If limit pool matched `seated.pool`, dropped override; if on another pool, retained override and set `inherited_override = true`. Journal line names whether override was dropped or kept.

4. **§5: Gating research and media orders on sources axis**
   - Added optional `sources` array of `{url, used_for}` to `REPORT_SCHEMA` and `REPORT_KEYS` in `src/nirvana_worker.rs`.
   - Added `sources_axis` in `src/nirvana_gate.rs` for `research.*` and `media.*` classes: fails if report has no sources; checks each source URL against real fetch/browser tool calls in worker stream (`WebFetch`, `mcp__*browser*`, agy `read_url_content`, `view_content_chunk`, `browser_*`, `call_mcp_tool` with browser). Normalizes scheme/host (lowercased), drops `www.`, equates `http`/`https`, drops trailing `/` and fragment. Never counts assistant text, thinking, or `tool_result` lines.
   - Extracted refusal and `--abandon` handling into pure function `end_decision(state: &RunState, args: &[String]) -> Result<Vec<Kind>, String>`. `end_cli` only calls `end_decision` and applies returned kinds.
   - Supported `herdr run end --abandon <order> --why <text>` to record an `abandoned` verdict so the run can end cleanly.
   - Updated `nirvana/claude/skills/gate/SKILL.md` documenting the sources axis and `--abandon`.

5. **§6: Requiring `owns:` line for build, fix, and plan orders**
   - Added `requires_owns(class: &str) -> bool` for `build.*`, `fix.*`, and `plan`.
   - In `nirvana_worker::seat_order`, checked `requires_owns(&booked.class)` after `book(project, request)` before worktree creation or worker startup, refusing missing `owns:` with exit 2.
   - In `nirvana_gate::owned_axis`, empty `owns` for `build.*`, `fix.*`, and `plan` returns `Mark::Fail` (`"unbounded: the order names no owned file"`), while other classes retain `Mark::Note`.
   - Documented requirements in `nirvana/claude/skills/gate/SKILL.md` and `nirvana/claude/skills/seat/SKILL.md`.
