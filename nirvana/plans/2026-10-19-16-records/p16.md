## What was built

- `src/nirvana_git.rs`:
  - `GitStatus`, `GitView`, `CiRun`, and `CiState` data representations.
  - Subprocess runner `run_cmd` with Windows `CREATE_NO_WINDOW`, 10s timeout for status/ci, 60s timeout for network commands, and `GIT_TERMINAL_PROMPT=0`.
  - Porcelain v2 parsing (`parse_porcelain_v2`) for branch, upstream, ahead/behind (+N -M), and changed file paths (including rename targets and untracked files).
  - Git square label computation (`git_label`) supporting wide (`main ↑1 ↓2 · 3 changed`), narrow (`main ↑1 ↓2 · 3`), clean branch (`main`), and CI status marks (`✓`, `✗`, `●`).
  - Action runners `pull_action`, `push_action`, and `fetch_action` implementing `stage_action` with `expect_branch` validation, upstream parsing, `--ff-only` for pull, and no-force push.
  - Background polling cache (`ENTRIES`, `poll`, `cached`, `refresh_folder`, `take_changed`) with 5s panel-open and 15s idle intervals, running completely off the draw path.
  - CI status reader (`read_ci_status`, `parse_ci_json`, `gh_env`) checking github.com remotes, parsing `gh run list --json` output, and setting `BROWSER`/`GH_BROWSER` to no-op with `GH_PROMPT_DISABLED=1`.
- `src/client/shell/nirvana_git.rs`:
  - `GitPanel`, `GitHits`, `GitButton`, and `GitConfirm` panel state structures.
  - `render_git_panel` drawing panel title, branch/upstream row, ahead/behind row, up to 8 changed file paths, CI status row, confirmation prompt (`Pull M commits from origin into main? N changed files in the tree.`), and `[Pull ↓M]`, `[Push ↑N]`, `[Fetch]` buttons.
  - Interactive event handling: `toggle_git_panel`, `git_action`, `route_git_key` (arrow key button selection, Enter action execution, Esc confirmation cancel / panel close), and `handle_git_mouse`.
- `src/client/shell/nirvana_mods.rs` & `src/client/shell/composition.rs`:
  - Mod strip layout integration placing the Git square next to Preload, Memory, and Jobs.
  - Drawing logic for wide and narrow strip forms, with active highlight (yellow) when ahead, behind, dirty, or CI failed.
  - Panel exclusivity: opening the Git panel closes all other panels, and opening any other panel closes the Git panel.
- Panel close sequences & `nirvana/controls.d/o8a.py`:
  - Added `self.nirvana_git = None;` across all panel close sequences (`nirvana_accounts.rs`, `nirvana_jobs.rs`, `nirvana_memory.rs`, `nirvana_mods.rs`, `nirvana_seats.rs`, `mouse.rs`).
  - Updated 8 `o8a_*` controls in `nirvana/controls.d/o8a.py` to maintain exact find text matching.
- `nirvana/controls.d/p16.py`:
  - 15 mutative sabotage controls covering every assertion in sections §2, §3, §4, §5.
