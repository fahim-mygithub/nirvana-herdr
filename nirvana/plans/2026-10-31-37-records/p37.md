## Where the plan or the order was silent, or I departed

1. **`blocked` deliveries are not auto-gated.** L3 says "every delivered order". A gate of a `blocked` report fails
   the report axis and seats a paid redo of a worker that said it cannot go on; the teaching path already gated only
   `done`. No incident backs either side. The owner's call to widen.
2. **Helpers are not auto-gated** (a review.adversary reviewer, a held-out author). Gating one gates or seats its
   subject's next step, whose `next` line the orchestrator acts on. They keep today's path: the wake says "delivered"
   and Nirvana Claude gates by hand.
3. **The wake carries the verdict only once `nirvana_run.rs` takes the hunk in the report.** The wake's digest is
   built from the journal's queue lines, and `Gated` has none on master. This package orders the gate before the wake
   (tested), so with the hunk the digest reads "o gated sent_back: <first failing axis>". Without it the wake still
   reads only "o delivered done", and a gate by hand returns the verdict already given.
4. **A `wait` verdict is not journaled** (as before), so a load-bearing order's wake says only "delivered"; ROLE step 5
   says to gate it by hand, which now gives the reviewer's line again.
5. **"Next stronger seat" is not defined in the plan.** The class score alone ties flash and argon; the table's seat
   order is not a strength order (fable is listed after haiku). The output price breaks the tie. The plan's wording
   "of the same class" is kept: only the class's seats are candidates.
