## Where the plan was wrong or silent

1. **`sse` is refused on agy.** The plan allows stdio, http or sse (§3.2). No probe measured sse, so it is refused, which
   is stricter than the plan. Owner's call to widen after a probe.
2. **A key outside `SERVER_KEYS` refuses the server on agy.** The plan lists only the keys to translate. Dropping an
   unknown key such as `disabled` or a timeout could change the server, and agy's `--settings` refused an unknown key at
   parse (plan probe 1). This is also stricter than the plan.
3. **`read_file(*)` may deny writes too** (probe 2). A `Read` denial on agy can therefore deny more than Claude's. It
   never denies less, so the row is kept, and the table's comment says so.
4. **`command(*)` shows up in the denial as `unsandboxed(...)`.** The rule still holds. The live check 5 text
   "Matches user-configured deny rule" is the same.
5. **The drive-stripped path form the docs describe is not what herdr writes.** It was not separated from the
   `read_file(*)` denial. Probe 1 measured the drive-kept form alone.
6. **The plan does not say to remove the folder before an attempt or after a failed argv build.** Both are done. A
   stale folder from a crash would otherwise reach the next start. An error in `with_profile` after `order_argv` wrote
   the servers would otherwise leave the token-bearing definitions until the run's cleanup. The second applies to
   claude's plan 29 file too.
7. **`key_clash` still refuses at the seat for either CLI.** On agy it is moot, because agy names tools by server name.
   I left it as it is, since `seat_needs` does not know the CLI.
