## What was built

- `src/nirvana_usage.rs`:
  - `Figure::Windows(Vec<Shown>)` variant added, with `Figure::windows(&self) -> Option<&[Shown]>` returning both `Window` and `Windows`.
  - `Figure::fill(&self)` updated to fill the bar using the tightest window from `Windows`.
  - `tightest_shown(windows: &[Shown]) -> Option<&Shown>` added.
  - `foot_rows(sources: &[Source; 4], now: u64) -> Vec<UsageRow>` builds footer rows: filters out dotted windows (`!reading.window.contains('.')`), sorts 5 h first then week, and gives each `Shown` its own `ahead` pace mark flag.
  - Preserved `pool_rows` unchanged for statusline and JSON usage (`herdr usage`).
- `src/client/shell/nirvana_footer.rs`:
  - Updated module sketch and header comment with owner's quote.
  - Constants added: `BOTH_FIGURE = 16`, `RESET_WIDTH = 6`, `WIDE_BOTH_FIGURE = 22`.
  - `format_window(shown: &Shown) -> String` formats single window `[pct]% [name][mark]`.
  - `figures` and `render_footer` render both windows when present, each styled independently (`text` when fresh, `overlay0` when stale, `peach` pace mark when ahead).
  - Preserved single `if wide {` in `figures` for reset calculation.
  - Dropping priority commented: bar dropped first when width < 3 between name and figures, then reset.
- `src/client/shell/tests/nirvana_footer.rs`:
  - Updated test usage helper with both 5 h and week windows for Claude and Gemini.
  - Asserted exact 25-cell narrow row fit: ` ● Claude 26% 5h  65% 7d▲`.
  - Updated wide sidebar tests for tightest reset (`6d18h` on Claude, `4h` on Gemini).
  - Added new tests: `a_pool_ahead_on_one_window_only_marks_that_window_alone`, `a_stale_week_beside_a_fresh_5h_is_muted_while_5h_is_fresh`, `a_one_window_pool_shows_that_single_window`, and `dotted_windows_are_never_shown_in_the_foot`.
- `nirvana/controls.d/foot2.py`:
  - Added 8 controls starting with `foot2_` for each assertion.
- `nirvana/controls.py`:
  - Updated `footer_no_pace_mark_text`, `footer_stale_not_muted`, and `usage_row_never_stale` find text to match updated code.
