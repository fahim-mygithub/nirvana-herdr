## 1. The validation (L3), measured 2026-10-19

- **No Claude agent drives Gemini today.**
  - Nirvana's `herdr seat run` starts agy straight in its own pane (`src/nirvana_worker.rs`, the `agy` argv with
    `--output-format stream-json`), with no Claude between.
  - My own plan 13 to 16 builds started agy from one Bash call (`scratchpad/p16/run.py`).
  - No subagent transcript on this machine from the last 10 days has a brief naming agy or a Gemini model, outside my
    own session's research workflows (`~/.claude/projects/*/*/subagents/*.meta.json`, grep for
    `gemini|agy|argon|flash|antigravity`; the two hits are a Haiku Preload read and a Sonnet model-research agent).
- **A Claude driver would cost more, so direct stays.**
  - A Claude subagent's first turn alone reads 17.6k to 55k tokens of context: the median over 172 general-purpose
    subagent transcripts is 54,856, the least is 17,576. Every wait turn re-reads it.
  - Direct costs the parent one tool call plus reading the final report.
- **Why it looked otherwise:** agy started outside herdr shows nowhere, so its work is invisible. §4 fixes that.
- **What Claude Code's token figure is.** The screenshot's `general-purpose ... 6m 59s · ↓ 133.7k tokens` matches the
  subagent's latest turn: input + cache read + cache write + output was 132,991 at 6m 32s, in
  `agent-a9fa6245448a13381.jsonl`. It is the subagent's current context, not its spend. Its spend over the 47 turns
  was many times that, since each turn re-reads the context.

## 2. The rows (L1, L2)

- **Under each agent row** in the left agents panel, one line per subagent of that pane. For example:

  ```
  3D-Printer-Flow-xtool
  claude
   ✻ general-purpose Sonnet 5.5   6m59s 133.7k
     Amazon-only parts research
   ◆ build Gemini 3.8 Flash       12m   1.2M
  ```

  - **The provider mark** comes first: `✻` in the Claude colour for Anthropic models, and `◆` in the Gemini colour for
    agy. These are the colours the usage foot already uses for the Claude and Gemini rows. A local model gets `●` in the
    Local colour.
  - **Then the name:** the subagent type or the order id. **Then the model,** spelled as the strip spells models
    (`Sonnet 5.5`, `Opus 5.5`, `Haiku 5.5`, `Gemini 3.8 Flash`, `Gemini 4 Argon`). A Claude subagent with no model
    in its transcript yet reads `inherit`.
  - **Then the status and the numbers.**
    - Running reads the elapsed time and the token figure.
    - Done reads `✓` with the elapsed time, and failed or stopped reads `✗`.
  - **The token figure is Claude Code's**, the latest turn's total, so the panel and Claude Code agree. agy's figure
    is the same shape: the latest step's input + output, from its stream.
  - **The second line** is the description, or the order's goal, dimmed. Narrow, it is dropped first, then the model's
    version number, then the elapsed time.
- **Which ones show:** running ones, and finished ones for 10 minutes after they end, dimmed. At most 6 per agent;
  more reads `+N more`. A workflow's agents nest one step deeper under the workflow's own row, by `parentAgentId`.
- **Clicking a subagent row** focuses its parent's pane, or the worker's own pane when it has one (a seat order).
- **The draw path reads nothing.** A poll off the draw path fills a cache per pane, every 2 s while any listed
  subagent runs and every 10 s otherwise, the same pattern as the Jobs and Git squares.
- **Panel layout:** the rows sit inside the existing agent row's height and scroll with it; `row_lines` counts them.
  The `grouped` view nests them under each agent, as the flat view does.

## 3. The Claude reader

- **The pane's session,** in this order:
  1. herdr's own `agent_session` for the pane, when Claude Code reported one;
  2. the Nirvana session record for the pane's folder (`nirvana_session_record::read`), when it is younger than the
     pane's agent;
  3. otherwise, the newest `<session>.jsonl` in `~/.claude/projects/<the folder encoded as Claude Code encodes it>/`
     written while the pane's agent ran.
  - When two Claude panes share one folder and nothing tells them apart, neither shows subagents. A wrong list is worse
    than none.
  - The owner's Claude Code does not register herdr's hook (measured 2026-10-19: `~/.claude/hooks/herdr-agent-state.ps1`
    exists but no settings file names it), so case 3 is the common one.
- **Its subagents** live in `<session>/subagents/agent-<id>.jsonl`, each with a `.meta.json` holding `agentType`,
  `description`, `model` and, on recent Claude Code, `finished: true`, plus `parentAgentId` for a workflow's agents.
  - **Running** means no `finished: true` and the transcript was written within the last 5 minutes. Older meta files
    have no `finished` key at all (871 of 957 on this machine), so the age rule stands in for them.
  - **The model** is the latest assistant message's `model`, mapped to the spelling above.
  - **The tokens** are the latest assistant message's usage, summed as above, read from the file's tail only. A
    transcript can be over 6 MB, so it is never read whole on a poll.
- **Claude Code's live activity line** ("Fetching FEIYASHI variant prices") is not on disk: it was in no file on
  2026-10-19. The row shows the description instead, and the record says so.

## 4. The agy readers (L4)

- **Seat orders** (`herdr seat run`) nest under the run's `orchestrator_pane`, from the run journal. The model and
  tokens come from the worker's stream (`nirvana_worker::Stream`, which already parses agy and Claude usage). An order
  whose worker has its own pane is not also listed as a separate agent row.
- **Jobs** (`herdr job run`) whose command is agy show under the pane that started them, with the model from the argv.
- **agy started from a Bash call** in a pane's Claude: a process walk finds `agy` processes under the pane's process.
  - The model comes from `--model` in its command line, so the row reads `◆ agy Gemini 3.8 Flash 12m`.
  - Tokens come from agy's own record of the conversation when one can be read: probe
    `~/.gemini/antigravity-cli/conversations/<id>.db` first, read only. Otherwise the row shows `-` for tokens, and
    the record says why.
- **Reads only.** Nothing here starts, signs in, or calls agy or gh. Any child process gets `CREATE_NO_WINDOW`.

## 5. Verification

- **Unit tests** on recorded files:
  - a meta and transcript pair for each case: running, finished with the flag, old with no flag, workflow child;
  - the model spellings;
  - the token figure: the tail read gives 132,991 on a recorded slice built like `agent-a9fa6245448a13381`;
  - the session resolution order and the shared-folder refusal;
  - agy argv to model; agy stream to tokens.
- **Client tests:** the rows under an agent, the marks and colours by provider, narrow and wide, the `+N more`, the
  10-minute dim, the click target, and `row_lines`.
- **Live:** in an isolated herdr server with a scratch `HOME` holding a recorded `.claude/projects` tree, a pane's
  rows show in a client snapshot. No test reads the real `~/.claude` or `~/.gemini`.
- **Every assertion gets a control** in `nirvana/controls.d/p17.py`.

## 6. Not in this version

- No stopping, steering or opening a subagent from the panel; it reads only.
- No live activity line, since Claude Code keeps it in memory only.
- No subagents of Codex or other agents.
