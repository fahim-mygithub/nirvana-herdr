# P38 build record: a space sparkles while anything under it is working

Plan: `nirvana/plans/2026-10-31-38-space-working-spinner.md`. Branch `p38-space-spinner` from da9f0193 (master
9304a821 plus the plan). Controls: `nirvana/controls.d/p38_spinner.py`, 15 controls, prefix `p38_`.

## What was built

- `src/nirvana_spaces.rs`: the frames `✧ ✦ ✶ ✷ ✸ ✷ ✶ ✦` (`SPARKLE_FRAMES`), 250 ms a frame (`SPARKLE_FRAME`), the
  fallback `◐`, one window-wide clock (`sparkle_frame`), and the repaint gate: the spaces list notes the frame it drew
  when a drawn space sparkled (`note_sparkle_drawn`), and `take_sparkle_due` answers yes only when that is so and the
  clock has moved to another frame. A yes forgets the drawing, so a repaint that draws no working space (the worker
  ended, the list hidden or scrolled) stops the repaints.
- `src/client/shell/nirvana_spaces.rs`: `space_working` (any agent of the space Working or Blocked, or a live worker
  row the list already read this frame; a folded worktree parent counts its hidden linked children's agents, as
  herdr's `displayed_workspace_status` does) and `space_marker` (sparkle in the working colour, Blocked keeps `×`,
  anything else today's marker). The tests are the `sparkle_tests` module at the end of this file.
- `src/client/shell/sidebar.rs`: `render_sidebar` reads one frame per list and passes the marker to a new
  `render_workspace_rows_with_marker`; `render_workspace_rows` keeps its signature for the endpoint sidebar and calls
  it with today's marker.

## Measurements

- Which agents fed the space marker before: the server's `Workspace::aggregate_state` (`src/workspace/aggregate.rs`)
  over the space's panes only, priority Blocked 4, Idle-unseen (Done) 3, Working 2. Seated workers that run off the
  space's panes (the live rows `space_workers` reads from the subagents cache) never fed it. Both causes of the
  owner's screenshot are real: Done outranks Working, and a seat worker is not a pane of the space.
- The client shows Done only for an agent it saw working (`endpoint_agent_state::projected_status`); the tests feed
  a Working snapshot before the Done one, or the space reads `○`.
- Width: `unicode-width` 0.2.2 (the crate the sidebar's `put_text` and `fit` use) gives 1 for all eight frames
  (`every_frame_is_one_cell_wide`); none falls back to `◐`. Not measured: the glyphs as drawn by JetBrains Mono in
  Windows Terminal.
- Repaints: the window's timer ticks every 100 ms (`ClientShellState::timer_delay`); with the tick line below, a
  working list repaints at most once per new frame (about 4 a second, as 300/200 ms steps on the 100 ms tick) and a
  list with nothing working adds none. The encoder (`blit_encoder.encode`) writes only cells that changed, so a
  sparkle repaint writes the marker cells (plus anything else that changed).
