## What Claude Code exposes (measured 2026-10-16, Claude Code 2.1.301)

- `claude -p /context --no-session-persistence --verbose --output-format json`, run in a folder, is answered by Claude
  Code itself: 0 tokens, a cost of 0, 2.6 s. With `--verbose` the answer is a list of events: `init` names the MCP
  servers (name, source, status), the plugins (name, id) and the tools; the local command's event carries
  `context_usage`, with every memory file, skill (source, plugin), custom agent and MCP tool and its tokens as integers,
  and the categories. Its total (29,094 in the Nirvana repo, 23,607 in a scratch folder) leaves out deferred tools.
  Without `--verbose` the answer is the markdown table alone.
- The switches, each proven by `/context` before and after (leaf "Sonnet - measure Claude preload toggles", 96 runs,
  every one free), from the folder's `.claude/settings.local.json` and from `--settings`:

  | Item | Setting | Before -> after |
  |---|---|---|
  | a CLAUDE.md, CLAUDE.local.md, .claude/CLAUDE.md, ~/.claude/CLAUDE.md | its absolute path, forward slashes, in `claudeMdExcludes` | Memory files 155 -> 98 (one file) |
  | auto memory | `autoMemoryEnabled: false` | Memory files 5,897 -> 1,995 (Nirvana repo) |
  | a user, project, built-in or claude.ai skill | `skillOverrides: {name: "off"}` | the skill's row gone |
  | a plugin | `enabledPlugins: {id: false}` | its skills, agents, MCP server and hook text gone |
  | an MCP server or claude.ai connector | `deniedMcpServers: [{serverName}]`, the `init` name | gone from `init`; bladebro -6.5k deferred |
  | a built-in tool | `permissions.deny: [name]` | Bash: System tools 5,381 -> 4,058 |
  | session-start hook text | `disableAllHooks: true` | Messages 1,620 -> 10 |

  Not switchable alone: a plugin's own skill (`skillOverrides` on it did nothing; its plugin is the switch) and a
  custom agent (`Agent(name)` in `permissions.deny` is checked only at spawn). `permissions.deny` on an MCP server hid
  its tools but left it connected with its instructions loaded, so servers use `deniedMcpServers`.
- Surprise kept for the owner: switching a skill off drops its row, but `/context`'s total does not fall; the Skills
  and System tools rows trade tokens one for one. Whether a session really saves those tokens needs a paid count.

## Shape

- **The strip.** One row under the tab bar, over a tab whose focused pane (else any pane) runs Claude Code, on an
  Anthropic or a local model. The panes are sized a row shorter, so nothing of theirs is covered. It reads
  `✻ Claude` in Claude's colour, then the one square: a bold " Preload " and the folder's preloaded total, "· N off"
  in yellow when the folder's settings switch items off, and ▾ (▴ while open). A tab without Claude has no strip.
- **The panel.** A click on the square opens it over the panes: "Preload · <folder>", "<total> of <window> preloaded ·
  Claude Code itself <system prompt>", where the switches go, then the groups in this order: CLAUDE.md and memory,
  Skills, MCP servers and connectors, Plugins, Agents, Built-in tools, Hooks. Each row: `[x]` on, `[ ]` off, `·` no
  switch of its own; the name, struck through when off; where it comes from; its tokens; "edit" when it is a file.
  Rows keep their place when switched (sorted by name in each group), and an item switched off stays listed with the
  tokens it had, because `/context` no longer lists it.
- **Keys.** ↑↓ / j k, PgUp PgDn, Home End move; space or enter switches; `e` opens the file in the editor; `r` restarts
  this Claude in the same folder and conversation (feature 2), so it takes the switches; esc or q closes. A click on a
  box switches it, on "edit" opens it, on "r restart Claude" restarts, outside the panel closes. Keys never reach the
  pane while the panel is open.
- **Switches** write only the item's own entry in the folder's `.claude/settings.local.json`, through a temporary file;
  switching back on removes it, and an emptied list or object is removed, so the file returns to what it was. A file
  that is not JSON is reported and never replaced. Every new Claude started in the folder, inside herdr or not, takes
  them; the running one takes them after a restart.
- **Edit** sends `command.invoke` with `nirvana.edit_file:<path>`; the server opens it in a zoomed pane with herdr's
  scrollback editor (`$VISUAL`, `$EDITOR`, else Notepad). The server opens only an existing absolute `.md` file.
- **Reading.** The window reads a folder's list on its own thread when the strip first shows it, when the panel opens,
  after each switch, and when it is older than ten minutes. A failed read keeps the last list.
- **Not the barebones.** Claude Code's own system prompt is not an item; the panel names its size in the summary.

## Record

Built 2026-10-16 on alpha 0.4.0 (485911db), as alpha 0.5.0. The parked 0.2.1 "Reload first" notice stays in `git stash`.

**Departures from the shape, found while building.**
1. *The panel keeps its own state, not one of herdr's overlays.* It is drawn after the panes and under herdr's own
   overlays, and takes keys and clicks before them while open; this left herdr's overlay enum and its exhaustive
   matches untouched.
2. *Switching writes the settings file with its keys in alphabetical order.* herdr's `serde_json` does not keep key
   order, and turning that on changes it for all of herdr. Claude Code rewrites the same file itself.

**Live run**, scratch home `scratchpad/nh-test5`, session `nirvana-s5`, folder `scratchpad/nirvana-preload-test` (a
CLAUDE.md and a project skill `preload-demo`), in a classic console window started minimized and shown behind every
other window without activation (`f5/behind.ps1`), captured with `PrintWindow` (`f4/capture-quiet.ps1`).
- `claude` started in the pane through `herdr pane run`, the folder trusted with two keys; herdr named the agent
  `claude`. Leaf agent "Sonnet - read Preload strip and panel shots" read `f5/shot-1-strip.png`: under the tab bar,
  one row "✻ Claude   Preload 23.4k ▾", the Preload part on a raised background (rgb 44,49,58 against 40,44,52),
  above the running Claude Code session. `/context` run by hand in the folder the same minute: 23,450.
- The click on the square was sent as console input (`f5/inject.ps1`), so no window would be raised. The injector
  failed (a `0xC0000000` PowerShell reads as a negative Int32), wrote its errors into the test window, and nothing
  reached herdr: `f5/shot-2-panel.png` holds the error text, not the panel. The owner then asked for the window to
  be closed; the session was stopped (`status: not running`).
- The panel was then drawn from that run's real `/context` answer (`f5/live-before.json`) by herdr's own compose, in a
  temporary test removed after one run: "Preload · nirvana-preload-test", "23.4k of 1m preloaded · Claude Code itself
  2.6k", "CLAUDE.md and memory 38", "[x] CLAUDE.md project 38 edit", "Skills 10k", user skills with "edit", plugin
  skills with "·" and "plugin claude-code-se…", and the key line; PageDown moved the list.
- The switches the panel writes, written to the folder's `.claude/settings.local.json` (CLAUDE.md in
  `claudeMdExcludes`, `preload-demo` off in `skillOverrides`): the next `/context` had no memory file and no
  `preload-demo`, total 23,450 -> 23,412 (the CLAUDE.md's 38; a skill switched off does not move the total, as the
  measuring leaf found). The file removed: both back, 23,450.

**Not measured.** A click and a key in a live window (the injector failed, then the window was closed at the owner's
word); the click and key paths are held by `nirvana_mods::*` and their controls. "edit" opening Notepad live. "r"
restarting from the panel (it sends feature 2's command, live-tested in feature 2). Whether a skill switched off saves
tokens in a real session (`/context` says the total stays; a paid count would settle it). An untrusted folder: Claude
Code's binary lists `claudeMdExcludes`, `enabledPlugins` and `disableAllHooks` among keys it drops from project
settings in an untrusted folder; `-p` honoured them, an interactive untrusted session was not tried.
