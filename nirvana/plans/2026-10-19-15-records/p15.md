## What was built

- `src/nirvana_job.rs`:
  - `JobRecord` representation with JSON serialization in `<home>/nirvana/jobs/<id>/job.json`.
  - Process tree termination via Windows ToolHelp32 snapshot and Win32 Job Objects.
  - `run_exec` executing child process with stdout/stderr line streaming to console and `out.log`, appending `[job <name>: exit N after Xs]`.
  - CLI commands: `herdr job run`, `exec`, `list`, `status`, `tail`, `stop`, and `clean`.
  - `open_job_pane` resolving or creating space, reusing/creating single "Jobs" tab, splitting panes side-by-side.
  - Claude Code background task parser (`%TEMP%/claude/<encoded>/<session>/tasks/*.output`), 12-hour active filter, 24-hour unknown state timeout.
  - `open_tail_pane` opening tail viewer for Claude tasks in the Jobs tab.
- `src/client/shell/nirvana_jobs.rs`:
  - Jobs square in mod strip: narrow (`2 run · 1 fail`) and wide (`Jobs 2 running · 1 failed`).
  - Dropdown panel listing active jobs and Claude background tasks with name, state, elapsed time, and last line.
  - Interactive mouse click handling to focus job pane or tail Claude tasks.
- `src/client/shell/nirvana_mods.rs` & `src/client/shell/composition.rs`:
  - Mod strip layout integration and background polling cache (2s active, 15s idle).
- `nirvana/claude/ROLE.md`:
  - Directive instructing agents to run builds, test suites, and gates longer than ~1 minute via `herdr job run`.
- `nirvana/claude/skills/jobs/SKILL.md`:
  - Skill file documenting `herdr job` commands, usage patterns, and examples.
- `nirvana/controls.d/p15.py`:
  - 12 mutative controls verifying each assertion against test targets.
