## What was built

- `src/nirvana_seats_v3.toml`:
  - Archived copy of previous default table added to `HISTORICAL_DEFAULTS[3]`.
- `src/nirvana_seats.toml`:
  - Shipped default table updated with measured `per_usd` rates (gemini week 0.00107, 5h 0.0021; google3p week 0.166, 5h 0.31).
  - Scaled use cells: flash scaled by 0.0396; g-opus and g-sonnet scaled by 0.221 (week) and 0.207 (5h).
  - All 19 class rows updated with multi-seat candidate lists, bars (Efficient / Balanced), and per-mode efforts (`efficient_effort`, `effort`, `sota_effort`).
  - Fallback seats (`g-opus`, `g-sonnet`) tagged `fallback = true`.
  - Added constants `climb_start = 0.70` and `climb_full = 1.00`.
- `src/nirvana_seat.rs`:
  - Added `fallback` field to `Seat` and `ClassSeat`, and `efficient_effort` / `sota_effort` fields to `Class` with serde defaults so v1-v3 tables parse seamlessly.
  - Implemented `effort_for(class, mode)` capping automatic efforts at `High` and recording `; capped at high` in `effort_note` when capped.
  - Efficient mode: enforces efficient bar and ranks by pressure, score, and class order at `efficient_effort`.
  - Balanced mode: evaluates surviving non-fallback seats to identify strongest surviving candidate and its hot pool, computes `climb = max((used + booked) / max(elapsed, pace_ease))`, scales `t = clamp((climb - 0.70) / 0.30, 0, 1)`, drops bar smoothly from balanced to efficient, and steps down hot pool effort by one step when `t >= 0.5`.
  - SOTA mode: evaluates candidates with bar 0.0 (all candidates in class enter ranking), ranks candidates strictly by score descending, bypassing pressure, climb, headroom filter 6, and reset discount.
  - Fallback ranking: `Candidate::tier` prioritizes primary candidates over `fallback` candidates across all three modes.
  - Upgrades: `maybe_upgrade` replaces historical defaults (v1-v3) with the new table while preserving user-selected `mode`.
- `src/nirvana_usage.rs`:
  - `agy_readings`: When agy `/usage` returns successfully with a Gemini group but omits Argon, synthesizes the Argon reading from `read_recent_orders` in `<home>/nirvana/seat_orders.jsonl` within the last 7 days with `source = "agy /usage: no Argon group, herdr's own count"`.
- `src/client/shell/nirvana_seats.rs` & `src/client/shell/nirvana_mods.rs`:
  - SOTA text rendered in `palette.red` in the Seats square title, the mode row (`[ Efficient ] [ Balanced ] [ SOTA ]`), and the mod strip Seats square when active; Efficient and Balanced retain existing theme colors.
- `nirvana/controls.d/p19.py`:
  - 15 sabotage controls covering every assertion in Plan 19.
