## What was built

1. **§2, B1 & S3: Worker pane closing and lifecycle safety**
   - **B1 Detached worker and title verification:** `open_pane` passes `--pane <id>` to `seat exec`. In `run_attempt`, the order's recorded pane is taken strictly from `--pane`, never falling back to `HERDR_PANE_ID`. Detached workers started inside Herdr record no pane and never close the caller's pane. Before any close in worker completion, `close_run_tab`, `tidy_cli`, or `cleanup_cli`, the pane's actual title is checked against `<seat>·<order>`. If mismatched, nothing is closed and a refusal reason is reported.
   - **S3 Tab run panes count under lock:** `tab_panes_count` counts only panes in the tab belonging to the current run's recorded panes. A per-run file lock protects the count-and-close critical section so concurrent finishing workers do not close the tab's last remaining pane.
   - Pure decision function `worker_should_close_pane(status, phase, pane_id, actual_title, expected_title, tab_panes_count) -> bool` ensures only `done` orders in `Delivered` phase with matching titles and `tab_panes_count > 1` close their pane.
   - Kept panes (blocked, failed, stopped, or undelivered) stay open.
   - Stream and work report remain readable on disk; `seat read <order>` works after pane close.

2. **§3, S4 & Review: Run end and run tidy**
   - **S4 Safe tab closure:** `close_run_tab` closes only panes belonging to finished orders (`Delivered`, `Gated`, `Merged`, `Interrupted`, `Failed`, `Reseated`). If a live order's pane is present in the tab, the tab is never closed; only eligible finished panes are closed.
   - Implemented `CloseRunTabDecision` enum and pure decision function `close_run_tab_decision`.
   - Wired `close_run_tab` directly into `herdr run end` CLI after printing the receipt.
   - Added `herdr run tidy` subcommand: iterates runs and acts only on ended runs (`state.ended.is_some()`) that have remaining worker panes, printing nothing for clean runs.

3. **§4, B3, S1 & S2: Spaces list agent rows**
   - **S1 26-cell row budget and ladder:** Row fits 26 cells preserving who, short model, and state. An unindented row has 19 text cells after its icon; an indented worktree row has 14 text cells. Implemented 5-step fallback ladder:
     1. `who`, short model, full state word, single-spaced, `who` padded to space's `max_who`;
     2. same with unpadded `who`;
     3. shortened state words (`working` -> `work`, `blocked` -> `wait`);
     4. model dropped;
     5. state word dropped (state color applied to `who`).
   - Short model function `compact_model` with comprehensive table test: Claude (`S5.5`, `O5.5`, `H5.5`, `F5.1`), Gemini (`Flash`, `Pro`), Codex (`Codex`), local models truncated to 6 cells.
   - **B3 Shared `is_nirvana_claude`:** Unified detection function in `src/nirvana_run.rs` checking `--agent nirvana` or `nirvana:nirvana` AND `--plugin-dir` equal by `folder_key` to home's `nirvana/claude`. Used by both `pane_program` and `probe`.
   - **S2 Hover chat title:** `MouseEventKind::Moved` over a space agent row records the hovered pane ID in `ClientShellState`. The hovered row displays the chat title (cut to fit) in place of model and state. Moving away clears hover. Focused pane retains its model and state. A row with empty task or "No task yet" shows nothing extra on hover.
   - Folded 2+ idle panes of the same kind without task into a single summary row (`▲ 2 agy panes  idle`).

4. **§5, B2, S6 & S7: Agents panel grouped workers**
   - **S6 Single grouping, sorting, and capping function:** `group_sort_and_cap_subagents` handles all run groups in one place. Runs sort by newest event time first. Live workers come first within each run, ordered newest first by elapsed time. Ended runs hide finished rows (ungated rows remain in receipt).
   - **Cap with count:** Counts drawn rows, preserves live workers first, and returns `cut_count`. The renderer renders `+N more` when rows are cut.
   - **B2 Finished worker phases:** Done shows `✓ done`, Blocked and Failed show `✗ blocked`/`✗ failed`, Stopped and Interrupted show `■ stopped`. Reseated orders are omitted. Dead and unreachable arms removed.
   - **S7 Fitted worker names:** Order names fitted so the status mark and state word are never pushed off screen, even at 26 cells.
   - In `agent_row`, clicking a finished worker whose pane was closed redirects to the orchestrator pane.

5. **§6 & Review: Controls**
   - 34 sabotage controls in `nirvana/controls.d/clear_sidebar.py` covering all B1-B3, S1-S7, and review behaviors.
   - All 1,271 controls verified matching exactly once in dry run and passing.

## Open Questions and Rulings

1. **Which sign marks Nirvana Claude:**
   - Shared `is_nirvana_claude` checking:
     1. `--agent nirvana` or `nirvana:nirvana`; AND
     2. `--plugin-dir` equal by `folder_key` to `<home>/nirvana/claude`.
   - *Reason:* Verified exact match ensures unrelated project folders containing "nirvana" in their path do not falsely identify a plain Claude session as Nirvana Claude.

2. **Hover or focused-pane title:**
   - Chat title shows on mouse hover via `MouseEventKind::Moved` over the space agent row.
   - Focused pane retains its model and state rather than substituting the title.
   - *Reason:* Herdr's terminal tracking enables any-event mouse tracking (`?1003h`). Handling `Moved` in `src/client/shell/mouse.rs` captures cursor location over space agent rows and triggers repaint, fulfilling the owner's choice L5.

## Discrepancies and Rulings ("The plan was wrong here")

1. **Space agent row width budget at 26 cells:**
   - At the default `sidebar_width: 26` the spaces list's area is 25 cells; the 26th column is the divider. Rows
     stop one cell short of the area's edge at every width, which leaves 19 cells after the icon, and 14 on an
     indented worktree row. (The first fix round special-cased `area.width == 25`; round 3 made it one rule.)
2. **Phase enum naming:**
   - In `src/nirvana_run.rs`, the enum variant for interrupted/stopped orders is `Phase::Interrupted`, with string representation `"interrupted"` or `"stopped"`. `SubagentState::Stopped` maps from `Phase::Interrupted` when outcome is `"stopped"`.
3. **Windows console UTF-8 output encoding:**
   - `nirvana/controls.py` reads and prints test output containing Unicode symbols (`●`, `✻`, `│`, `✓`, `✗`, `■`). On Windows PowerShell, Python defaults to `cp1252`, causing `UnicodeEncodeError`. Setting `$env:PYTHONIOENCODING="utf-8"` is required for dry-run and control execution.
