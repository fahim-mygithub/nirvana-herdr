## What was built

1. **§2: The project's mode file (`<project>/.nirvana/seats.toml`)**
   - Implemented `project_seats_path(root: &Path) -> PathBuf`.
   - Implemented strict parser `parse_project_seats(path: &Path, text: &str) -> Result<Mode, String>` ensuring only `mode = ...` is permitted, rejecting unknown keys, extra sections, or bad values with file path and line number.
   - Implemented `with_project_mode(text: &str, mode: Mode) -> Result<String, String>` and `set_project_mode(root: &Path, mode: Mode) -> Result<Option<Mode>, String>` preserving comments and line formatting while writing atomically via `write_atomic`.

2. **§3: Precedence resolution and `table_for`**
   - Added `ModeSource` enum with variants `Project` and `Machine`, and method `word()`.
   - Implemented `project_mode(root: &Path, table: &Table) -> Result<(Mode, ModeSource), String>`: no file defaults to machine table mode; existing file yields project mode.
   - Implemented `table_for(root: &Path) -> Result<Table, String>` returning global table with project's mode.
   - Updated callers in `nirvana_seat::orchestrator_cli`, `nirvana_seat::list_cli`, `nirvana_seat::pick_cli`, `nirvana_gate.rs` (lines 1473, 2414), `nirvana_worker.rs` (rate limiting, order bookings, and seat order dispatching).

3. **§4: Setting the mode**
   - Implemented `change_mode(root: &Path, to: Mode, by: &str)` writing project `.nirvana/seats.toml` and logging `mode_changed` in open runs of that project.
   - Implemented `change_machine_mode(root: &Path, to: Mode, by: &str)` updating global line and logging in project runs.
   - Implemented `clear_mode(root: &Path, by: &str)` removing project `.nirvana/seats.toml` so project follows machine.
   - Implemented `mode_cli_for(root: &Path, args: &[String])` and `mode_cli(args: &[String])` handling no args (printing mode and source), `<mode>`, `--machine <mode>`, and `--clear`.
   - Updated USAGE string with clear explanations of project vs machine modes.

4. **§5: The orchestrator's seat**
   - Implemented `orchestrator_launch_seat_for(home: &Path, folder: &Path) -> (String, String)` in `nirvana_launch.rs` ensuring each workspace's Nirvana Claude starts with model and effort dictated by its project mode.
   - Updated `nirvana_claude::session_start_cli` to pass folder to `orchestrator_launch_seat_for`.
   - Updated `check_seat_notice(session, root: Option<&Path>)` and `run_notice` in `nirvana_board.rs` to isolate restart notices per project.

5. **§6: Visual indicators in Seats square**
   - Added `mode_source: Option<ModeSource>` to `nirvana_seats_square::View`.
   - Updated `Line::Mode` in `client/shell/nirvana_seats.rs` to render `· this project` or `· machine` beside the mode selectors.
   - Maintained SOTA red coloring and preserved click-to-cycle and `m` key navigation behaviors.
